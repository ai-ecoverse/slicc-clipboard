# slicc-clipboard

`@ai-ecoverse/slicc-clipboard`: `pbcopy`, `pbpaste`, `xclip`, `xsel`, `wl-copy`, `wl-paste`, `sccopy` and `scpaste` as POSIX `sh` in `bin/` over the kernel's `/dev/clipboard`, and `sccopy`/`scpaste` for hosts as Node in `host/`. README.md is the spec. No comments in any file. No CLAUDE.md. Write to the device through coreutils `cat`, never a builtin. The scripts use only `/dev/clipboard`, failing when it isn't a character device. Unit tests live in the gitignored `test/unit/` (sh under dash and bash; `npm run test:unit` writes coverage to `coverage/unit/lcov.info`; the pre-commit hook wants 100% of changed lines); committed tests in `test/integration/`. Host tests touch the real clipboard only on CI. `npm run lint` and `npm test` must pass. Never use ports 9222-9229. Releases come from `main` via semantic-release; never move or delete a pushed tag.
