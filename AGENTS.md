# slicc-clipboard

The npm package `@ai-ecoverse/slicc-clipboard`: `pbcopy`, `pbpaste`, `xclip`, `xsel`, `wl-copy` and `wl-paste` as POSIX `sh` scripts in `bin/`, over the kernel's `/dev/clipboard`. README.md is the spec; keep it in step. No comments in any file, YAML included. No CLAUDE.md. Write to the device through coreutils `cat`, never a builtin, so close() errors reach us. The scripts always use `/dev/clipboard`, failing when it isn't a character device; unit tests run copies pointed at a temp file. Unit tests live in the gitignored `test/unit/` (run under dash and bash; `npm run test:unit` writes shell line coverage to `coverage/unit/lcov.info`, and the pre-commit hook wants 100% of changed lines); integration tests in `test/integration/` run on `@ai-ecoverse/slicc-kernel/node`. `npm run lint` and `npm test` must pass. Never use ports 9222-9229. Releases come from `main` via semantic-release; never move or delete a pushed tag.
